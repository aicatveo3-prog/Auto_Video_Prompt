# 📝 STEP 2: 이미지 생성 프롬프트

> STEP 1(기획)이 완성된 후, 이 프롬프트로 각 장면의 AI 이미지 생성 프롬프트를 만듭니다.

---

## 사용 방법

1. STEP 1의 기획 결과가 같은 대화에 있는지 확인
2. 아래 프롬프트를 복사하여 붙여넣기
3. 전송!

> 💡 다른 채팅이라면 STEP 1의 기획 결과를 함께 붙여넣으세요.

---

## 프롬프트 원본

```
당신은 AI 이미지 생성 전문가입니다. 위에서 완성한 영상 기획을 바탕으로, 각 장면에 필요한 AI 이미지 생성 프롬프트를 작성해주세요.

---

## 이미지 프롬프트 작성 규칙:

### 1. 기본 원칙
- 기획에서 정한 아트 스타일을 모든 프롬프트에 일관되게 적용
- 캐릭터 외형 묘사를 매 프롬프트마다 동일하게 반복 (일관성 유지가 최우선)
- 배경/로케이션도 동일한 세계관 안에서 유지
- 이미지 1장당 1개의 프롬프트

### 2. 프롬프트 구조 (각 프롬프트에 반드시 포함할 7가지 요소)

[스타일]: 아트 스타일, 렌더링 품질, 조명 방향
  예: "3D rendered felt plush toy style, soft lighting, high quality, cute aesthetic"

[캐릭터]: 주인공/서브캐릭터 외형 상세 묘사 (매번 동일하게!)
  예: "A small plush character with blue curly hair, beige skin, wearing a white t-shirt and black shorts, blue sneakers"

[동작/포즈]: 캐릭터가 취하고 있는 자세와 표정
  예: "standing with arms raised, happy smile, eyes closed"

[배경]: 장소, 소품, 분위기 상세
  예: "colorful outdoor festival with booth stalls, bunting flags, balloons"

[구도]: 카메라 앵글
  예: "front view", "back view", "side view", "close-up", "wide shot"

[시간대/조명]: 시간과 조명 분위기
  예: "bright daytime, warm sunlight" / "golden hour sunset" / "evening with string lights"

[감정]: 이 장면에서 전달해야 할 감정 (프롬프트 마지막에)
  예: "conveying pure joy and excitement"

### 3. 출력 형식
- 이미지 번호와 장면명을 헤더(##)로 구분
- 영어 프롬프트를 코드블록 안에 작성
- 프롬프트 아래에 한국어로 "이 이미지의 핵심 포인트" 간단 설명 (2~3줄)
- 마지막에 전체 이미지 목록 요약표 (표: 번호, 장면명, 구도, 시간대, 감정)

### 4. 일관성 체크
- 마지막에 "🔍 일관성 체크리스트"를 만들어서 다음을 확인:
  - [ ] 모든 프롬프트에서 캐릭터 외형 묘사가 동일한가?
  - [ ] 아트 스타일 키워드가 통일되었는가?
  - [ ] 배경이 같은 세계관인가?
  - [ ] 시간대 변화가 기획과 일치하는가?
  - [ ] 구도가 기획의 의도와 맞는가?

### 5. 승인 게이트

⚠️ 모든 이미지 프롬프트를 출력한 후, 반드시 아래 승인 요청을 붙이세요:

---
### 🔒 승인 요청
위 이미지 프롬프트를 확인해주세요.
- ✅ **승인** → STEP 2 완료! 이미지를 생성한 뒤 STEP 3으로 진행할 수 있습니다.
- ✏️ **수정** → 수정할 이미지 번호와 내용을 알려주세요
- 🔄 **재작업** → 전체 이미지 프롬프트를 처음부터 다시 합니다
---

사용자가 승인하기 전까지 절대 STEP 3를 시작하지 마세요.
사용자가 "STEP 3 시작해"라고 말하고 이미지를 첨부해야 STEP 3을 시작합니다.

---

위의 기획 내용을 바탕으로 모든 이미지 프롬프트를 작성해주세요.
```

---

## 기대 출력물

```
✅ 이미지별 영어 프롬프트 (코드블록)
✅ 각 이미지 핵심 포인트 (한국어)
✅ 전체 이미지 목록 요약표
✅ 일관성 체크리스트
```

> 이 프롬프트로 생성한 이미지가 STEP 3(이미지 투 비디오)의 입력이 됩니다.

---

## 💡 팁

- 이미지 생성 도구마다 최적 프롬프트 형식이 다릅니다 (Midjourney, DALL-E, Stable Diffusion 등)
- AI에게 **어떤 도구를 사용할지** 미리 알려주면 그에 맞게 최적화해줍니다
- 캐릭터 일관성이 안 나오면 **참조 이미지(reference image)** 기능을 활용하세요
- 한 번에 모든 이미지를 완벽하게 만들 필요 없습니다 — 반복 생성으로 베스트를 고르세요
