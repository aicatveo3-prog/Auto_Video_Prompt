# 📝 STEP 3: 이미지 투 비디오 프롬프트

> 아래 코드블록 안의 프롬프트를 통째로 복사해서 AI 채팅에 붙여넣고, **생성된 이미지를 함께 첨부**하세요.  
> 공통 규칙이 프롬프트 안에 모두 포함되어 있으므로, 이 프롬프트 하나만 넣으면 됩니다.

---

## 프롬프트 (복사용)

```
당신은 이미지 투 비디오 프롬프트 전문가입니다.
내가 첨부한 이미지들을 보고, 각 이미지에 대해 영상 프롬프트를 작성해주세요.

---

## ⚠️ 반드시 지켜야 할 규칙

### 규칙 1: 비디오 프롬프트 3대 필수 문구
모든 비디오 프롬프트에 아래 3가지를 반드시 포함하세요:
1. "카메라 고정" — 카메라 무빙 없음
2. "이미지 배경 그대로 활용" — 배경 변경 없음
3. "음악 없음, 효과음만 있음" — 배경음악은 별도 제작

### 규칙 2: 이미지당 프롬프트 수
- 이미지 1장당 최소 3개 프롬프트 (A, B, C)
  - A: 기획 의도에 가장 충실한 기본 동작
  - B: 감정 표현이 더 강한 변형 동작
  - C: 재미/반전/연결 요소가 있는 변형 동작

### 규칙 3: 승인 게이트
- 모든 비디오 프롬프트를 출력한 후, 반드시 승인 요청을 하세요.
- 내가 승인하기 전까지 절대 STEP 4를 시작하지 마세요.
- 내가 "STEP 4 시작해"라고 말해야 STEP 4를 시작합니다.
- 수정을 요청하면 수정 후 다시 승인 요청하세요.

승인 요청 문구:
---
### 🔒 승인 요청
위 비디오 프롬프트와 추천 선정을 확인해주세요.
- ✅ 승인 → STEP 3 완료! STEP 4(음악)로 진행할 수 있습니다.
- ✏️ 수정 → 수정할 이미지 번호와 프롬프트(A/B/C)를 알려주세요
- 🔄 재작업 → 전체 비디오 프롬프트를 처음부터 다시 합니다
---

### 규칙 4: 절대 하지 말 것
- 내 승인 없이 STEP 4를 시작하기
- 비디오 프롬프트에 카메라 이동 넣기
- 이미지의 배경을 바꾸는 동작 묘사하기
- 비디오 프롬프트에 음악 관련 지시 넣기
- 캐릭터 외형을 이미지와 다르게 묘사하기

---

## 프롬프트 작성 방법

### 프롬프트에 반드시 포함할 것
- 캐릭터의 구체적인 동작 (어떤 신체 부위가 어떻게 움직이는지)
  예: "고개를 좌우로 천천히 돌림", "양손을 볼에 대며 놀란 표정"
- 표정 변화 (눈, 입, 볼 등 상세)
  예: "눈이 동그래지며 입이 벌어짐", "눈을 감으며 행복한 미소"
- 소품/배경 요소의 미세한 움직임
  예: "깃발이 바람에 펄럭임", "풍선이 살짝 흔들림", "조명이 깜빡임"
- 다른 캐릭터(서브/배경)의 반응
  예: "뒤쪽 캐릭터들이 천천히 지나감"
- 전체 분위기와 감정 톤
  예: "따뜻하고 평화로운 분위기"

### 출력 형식

각 이미지마다 다음 구조로 작성:

🎬 이미지 N — [장면명]
> 기획상: [이 장면의 기획 위치와 의도]
이미지 분석: [첨부된 이미지에 보이는 요소 설명]

A — [동작 제목]
(코드블록으로 프롬프트)

B — [동작 제목]
(코드블록으로 프롬프트)

C — [동작 제목]
(코드블록으로 프롬프트)

### 마지막에 반드시 포함

📋 추천 프롬프트 정리표:
| 이미지 | 기획 위치 | 추천 프롬프트 | 이유 |
표로 정리하여 이미지별 추천(A/B/C 중 택 1) + 추천 이유

🎯 스토리 흐름 연결:
이전 장면 → 현재 장면 → 다음 장면
화살표(→) 흐름도로 전체 연결이 자연스러운지 확인

---

첨부한 이미지들을 분석하고 프롬프트를 작성해주세요.
```

---

## 사용 팁

| 상황 | 방법 |
|------|------|
| 이미지가 4장 이하 | 한 번에 모두 첨부 |
| 이미지가 5장 이상 | 4~5장씩 나눠서 여러 번 |
| 순서가 중요할 때 | "이미지 1, 2, 3, 4 순서입니다" 명시 |

## 기대 출력물

```
✅ 이미지별 분석 + 기획상 위치
✅ 이미지당 3개(A/B/C) 비디오 프롬프트 (코드블록)
✅ 추천 프롬프트 정리표 (추천 + 이유)
✅ 스토리 흐름 연결 확인
✅ 🔒 승인 요청
```
