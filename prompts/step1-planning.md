# 📝 STEP 1: 기획 프롬프트

> 이 프롬프트를 AI 채팅에 붙여넣고, 원하는 영상 주제만 입력하면 기획이 완성됩니다.

---

## 사용 방법

1. 아래 프롬프트를 복사
2. AI 채팅에 붙여넣기
3. 맨 아래 `[여기에 주제를 입력]` 부분에 원하는 영상 주제 작성
4. 전송!

---

## 프롬프트 원본

```
당신은 전문 영상 기획자입니다. 내가 만들고 싶은 영상의 주제/컨셉을 알려줄 테니, 아래 포맷에 맞춰 영상 기획을 완성해주세요.

---

## 기획 작성 규칙:

### 1. 프로젝트 개요
- 프로젝트 유형 (단편 애니메이션, 뮤직비디오, 브이로그, 광고 등)
- 주인공 캐릭터 설정 (외형, 성격, 특징을 아주 상세하게)
- 서브 캐릭터 설정 (있을 경우, 동일한 상세도로)
- 전체 배경/로케이션
- 아트 스타일 (3D, 2D, 실사, 봉제인형 등)
- 제작 방식: AI 이미지 생성 → 이미지 투 비디오 → AI 음악 생성 → 편집

### 2. 전체 스토리 구조
- 시작 → 전개 → 전환 → 발전 → 클라이맥스 → 해소 → 엔딩 구조로 작성
- 화살표(→)를 사용한 흐름도로 먼저 보여주기
- 각 단계가 왜 필요한지 간단한 이유도 함께
- 전체 스토리를 한 문장으로 요약하는 로그라인도 포함

### 3. 파트별 상세 기획
- 파트 번호, 파트명, 기획 의도, 감정선(이모지 포함)을 표로 작성
- 감정선 이모지 규칙:
  - 🟡 기대, 호기심, 설렘
  - 🟢 행복, 기쁨, 즐거움
  - 🔴 놀람, 긴장, 위기
  - 💙 감동, 여운, 잔잔함
- 각 파트가 다음 파트로 어떻게 연결되는지 전환 로직도 명시

### 4. 감정 곡선
- 전체 영상의 감정 강도를 시간 순서대로 텍스트 그래프로 시각화
- 가장 높은 감정 피크에 ⭐ 표시
- 감정이 올라가는 구간, 내려가는 구간, 전환점을 명확히

### 5. 필요한 이미지 목록
- 각 파트별로 필요한 이미지를 목록으로 정리
- 표로 작성: 이미지 번호, 장면 설명, 구도(정면/뒷모습/클로즈업 등), 시간대(낮/석양/밤), 핵심 요소
- 총 몇 장의 이미지가 필요한지 합계
- 이미지 간 연결성 (같은 장소에서 시간만 다른 경우 등) 표시

### 6. 기획 완료 체크리스트
- 기승전결 구조가 있는가?
- 감정선에 변화가 있는가?
- 클라이맥스가 명확한가?
- 파트 간 전환이 자연스러운가?
- 필요 이미지 목록이 빠짐없이 완성되었는가?
- 캐릭터 설정이 이미지 생성에 충분히 상세한가?

---

내가 만들고 싶은 영상 주제:
[여기에 주제를 입력]
```

## 주제 입력 예시

| 예시 | 입력 내용 |
|------|-----------|
| 캐릭터 애니메이션 | "봉제인형 스타일 고양이 캐릭터가 카페에서 하루를 보내는 힐링 영상" |
| 모험 스토리 | "우주를 탐험하는 작은 로봇의 모험 단편 애니메이션" |
| 뮤직비디오 | "벚꽃이 흩날리는 봄날, 두 친구의 우정을 그린 감성 뮤직비디오" |
| 브이로그 | "귀여운 곰 캐릭터의 제주도 여행 브이로그" |
| 광고 | "핸드메이드 악세서리 브랜드의 따뜻한 분위기 제품 소개 영상" |

## 기대 출력물

이 프롬프트를 실행하면 다음을 얻을 수 있습니다:

```
✅ 프로젝트 개요 (표)
✅ 스토리 구조 흐름도
✅ 파트별 상세 기획 (표)
✅ 감정 곡선 시각화
✅ 필요 이미지 목록 (표)
✅ 기획 완료 체크리스트
```

> 이 출력물이 STEP 2(이미지 생성)의 입력이 됩니다.

## 💡 팁

- 주제를 **구체적으로** 쓸수록 기획 품질이 올라갑니다
- 캐릭터가 이미 있다면 외형을 상세히 설명해주세요
- 원하는 분위기나 참고 작품이 있다면 함께 언급하세요
- 기획 결과가 마음에 안 들면 특정 파트만 수정 요청 가능합니다
