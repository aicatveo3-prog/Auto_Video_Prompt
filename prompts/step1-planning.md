# 📝 STEP 1: 기획 프롬프트

> 기획은 가장 중요한 단계입니다. **4개의 서브 단계**로 나뉘며, 각 단계마다 사용자의 **승인을 받아야** 다음으로 넘어갑니다.

---

## ⚠️ 핵심 규칙: 승인 게이트

```
🚫 절대 금지: 사용자의 명시적 승인 없이 다음 단계로 넘어가는 것
✅ 필수: 각 서브 단계(1-A → 1-B → 1-C → 1-D) 완료 후 승인 요청
✅ 필수: STEP 1 전체 완료 후 최종 승인 → 그래야 STEP 2로 진행 가능
```

---

## 📌 STEP 1의 4개 서브 단계

```
STEP 1-A: 컨셉 & 캐릭터 설정  →  🔒 승인 게이트
    ↓
STEP 1-B: 스토리 구조          →  🔒 승인 게이트
    ↓
STEP 1-C: 파트별 상세 기획     →  🔒 승인 게이트
    ↓
STEP 1-D: 이미지 목록 확정     →  🔒 승인 게이트
    ↓
🔒 STEP 1 최종 승인 → STEP 2로 진행 가능
```

---

## 사용 방법

1. 아래 프롬프트를 복사하여 AI 채팅에 붙여넣기
2. 영상 주제를 입력
3. AI가 **STEP 1-A만 먼저** 출력
4. 확인 후 승인/수정 지시
5. 승인하면 AI가 1-B를 출력... 반복
6. STEP 1-D까지 모두 승인하면 최종 기획서 완성!

---

## 프롬프트 원본

```
당신은 전문 영상 기획자입니다. 내가 만들고 싶은 영상의 주제/컨셉을 알려줄 테니, 아래 규칙에 따라 기획을 진행해주세요.

---

## ⚠️ 가장 중요한 규칙: 승인 게이트 시스템

이 기획은 4개의 서브 단계로 나뉩니다. 반드시 다음 규칙을 지키세요:

1. 한 번에 하나의 서브 단계만 출력하세요.
2. 각 서브 단계를 출력한 후, 반드시 아래 승인 요청 문구를 붙이세요:

---
### 🔒 승인 요청
위 내용을 확인해주세요.
- ✅ **승인** → 다음 단계로 진행합니다
- ✏️ **수정** → 수정할 부분을 알려주세요
- 🔄 **재작업** → 이 단계를 처음부터 다시 합니다
---

3. 사용자가 "승인", "ok", "좋아", "넘어가", "다음" 등 명시적으로 승인하기 전까지 절대 다음 단계로 넘어가지 마세요.
4. 사용자가 수정을 요청하면 수정 후 다시 승인 요청하세요.
5. 모든 서브 단계(1-A ~ 1-D)가 승인된 후에만 STEP 1이 완료됩니다.
6. STEP 1이 완료되어도, 사용자가 "STEP 2 시작해"라고 말하기 전까지 STEP 2를 시작하지 마세요.

---

## STEP 1-A: 컨셉 & 캐릭터 설정

다음을 작성해주세요:

### 프로젝트 개요 (표)
- 프로젝트 유형 (단편 애니메이션, 뮤직비디오, 브이로그, 광고 등)
- 전체 배경/로케이션
- 아트 스타일 (3D, 2D, 실사, 봉제인형 등)
- 전체 분위기/톤
- 제작 방식: AI 이미지 생성 → 이미지 투 비디오 → AI 음악 생성 → 편집

### 캐릭터 설정
주인공 캐릭터:
- 이름
- 외형 상세 (머리, 얼굴, 체형, 피부색, 특징)
- 의상 상세 (상의, 하의, 신발, 악세서리)
- 성격 키워드 (3~5개)
- 이 캐릭터의 핵심 매력

서브 캐릭터 (있을 경우 동일한 상세도로):
- 동일한 항목 모두 작성

배경 캐릭터 (있을 경우):
- 어떤 종류의 캐릭터들이 등장하는지

→ 출력 후 🔒 승인 요청

---

## STEP 1-B: 스토리 구조

(1-A 승인 후 진행)

다음을 작성해주세요:

### 로그라인
- 전체 스토리를 한 문장으로 요약

### 스토리 구조 흐름도
- 시작 → 전개 → 전환 → 발전 → 클라이맥스 → 해소 → 엔딩
- 화살표(→) 흐름도로 표현
- 각 단계에 무슨 일이 일어나는지 한 줄 설명
- 각 단계가 왜 필요한지 이유

### 감정 곡선
- 전체 감정 강도를 텍스트 그래프로 시각화
- 가장 높은 피크에 ⭐ 표시
- 감정 올라가는 구간, 내려가는 구간, 전환점 명시

→ 출력 후 🔒 승인 요청

---

## STEP 1-C: 파트별 상세 기획

(1-B 승인 후 진행)

다음을 작성해주세요:

### 파트별 상세 기획표
표로 작성:
| 파트 | 파트명 | 기획 의도 | 감정선 | 전환 로직 |

감정선 이모지 규칙:
- 🟡 기대, 호기심, 설렘
- 🟢 행복, 기쁨, 즐거움
- 🔴 놀람, 긴장, 위기
- 💙 감동, 여운, 잔잔함

### 각 파트 상세 설명
파트마다:
- 무슨 일이 일어나는지 (2~3문장)
- 캐릭터의 감정/행동
- 이전 파트에서 어떻게 연결되는지
- 다음 파트로 어떻게 이어지는지

→ 출력 후 🔒 승인 요청

---

## STEP 1-D: 이미지 목록 확정

(1-C 승인 후 진행)

다음을 작성해주세요:

### 필요 이미지 목록
표로 작성:
| 번호 | 파트 | 장면 설명 | 구도 | 시간대 | 핵심 요소 |

- 총 몇 장 필요한지 합계
- 이미지 간 연결성 표시 (같은 장소, 시간 변화 등)
- 어떤 이미지가 가장 중요한지 ⭐ 표시

### 기획 완료 체크리스트
- [ ] 기승전결 구조가 있는가?
- [ ] 감정선에 변화가 있는가?
- [ ] 클라이맥스가 명확한가?
- [ ] 파트 간 전환이 자연스러운가?
- [ ] 필요 이미지 목록이 빠짐없는가?
- [ ] 캐릭터 설정이 이미지 생성에 충분히 상세한가?

→ 출력 후 🔒 승인 요청

---

## STEP 1 최종 확인

모든 서브 단계(1-A ~ 1-D)가 승인되면:

"🎉 STEP 1 기획이 완료되었습니다!
사용자가 'STEP 2 시작해'라고 말하면 이미지 생성 단계로 넘어갑니다.
그 전까지는 기획 내용에 대한 수정이나 질문을 받겠습니다."

라고 안내하세요. 절대 자동으로 STEP 2를 시작하지 마세요.

---

내가 만들고 싶은 영상 주제:
[여기에 주제를 입력]
```

## 진행 흐름 요약

```
사용자: 주제 입력
  ↓
AI: STEP 1-A 출력 + 🔒 승인 요청
사용자: 승인 / 수정 요청
  ↓
AI: STEP 1-B 출력 + 🔒 승인 요청
사용자: 승인 / 수정 요청
  ↓
AI: STEP 1-C 출력 + 🔒 승인 요청
사용자: 승인 / 수정 요청
  ↓
AI: STEP 1-D 출력 + 🔒 승인 요청
사용자: 승인 / 수정 요청
  ↓
AI: "STEP 1 완료! STEP 2를 시작하려면 말씀해주세요."
사용자: "STEP 2 시작해"
  ↓
→ STEP 2 진행
```

## 💡 팁

- 주제를 **구체적으로** 쓸수록 기획 품질이 올라갑니다
- 캐릭터가 이미 있다면 외형을 상세히 설명해주세요
- 원하는 분위기나 참고 작품이 있다면 함께 언급하세요
- **수정 요청은 여러 번 해도 괜찮습니다** — 기획이 마음에 들 때까지!
- 승인 후에도 이전 단계로 돌아가서 수정할 수 있습니다
