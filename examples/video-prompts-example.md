# 💡 비디오 프롬프트 예시 — 축제 프로젝트

> STEP 3(이미지 투 비디오) 프롬프트를 실행했을 때 나오는 결과물의 실제 예시입니다.  
> 이미지 3장에 대한 예시를 보여줍니다.

---

## 공통 규칙 확인

모든 프롬프트에 포함된 3대 필수 문구:
- ✅ "카메라 고정"
- ✅ "이미지 배경 그대로 활용"
- ✅ "음악 없음, 효과음만 있음"

## 🎬 예시 1 — 부스 앞 마주침 (만남 장면)

> 기획상: 파트6 — 파발이가 축제를 돌아다니다가 영꾸꾸를 우연히 발견! "어?! 영꾸꾸?!"

**이미지 분석**: 두 캐릭터가 문구/장난감 부스 앞에서 놀란 표정으로 마주보고 있음. 머리 위에 느낌표 이펙트. 왼쪽 "STATIONERY TOYS" 부스, 오른쪽 "PLAY LEARN GROW" 부스.

### A — 깜짝 놀라며 마주침

```
카메라 고정. 이미지 배경 그대로 활용. 두 캐릭터가 부스 앞에서 우연히 마주침. 파란 머리 캐릭터가 놀란 표정으로 입을 벌리고 뒤로 살짝 젖혀짐. 초록 비니 캐릭터도 눈이 커지며 놀란 리액션. 머리 위에 놀람 이펙트(느낌표). 양쪽 부스의 문구류와 장난감이 배경에 보임. 음악 없음, 효과음만 있음.
```

### B — 반갑게 손 흔들기

```
카메라 고정. 이미지 배경 그대로 활용. 파란 머리 캐릭터가 초록 비니 캐릭터를 발견하고 반갑게 손을 크게 흔듦. 초록 비니 캐릭터도 알아보고 양손을 들어 흔들며 다가옴. 두 캐릭터가 서로를 향해 한두 걸음 가까워짐. 부스 앞 밝은 분위기. 음악 없음, 효과음만 있음.
```

### C — 놀라서 서로 가리키기

```
카메라 고정. 이미지 배경 그대로 활용. 파란 머리 캐릭터가 초록 비니 캐릭터를 발견하고 손가락으로 가리키며 놀란 표정. 초록 비니 캐릭터도 동시에 파란 머리 캐릭터를 가리킴. 둘 다 입을 벌린 채 놀라는 동작. "STATIONERY TOYS" 부스와 "PLAY LEARN GROW" 부스 사이 공간에서 마주침. 음악 없음, 효과음만 있음.
```

## 🎬 예시 2 — 풍선 날아감 (석양 클라이맥스)

> 기획상: 파트10 — 풍선에 영꾸꾸가 둥실 떠오름! 파발이가 필사적으로 잡는 극적 장면 ⭐

**이미지 분석**: 석양빛 축제장. 초록 비니 캐릭터가 알록달록 풍선에 매달려 공중에 떠있음. 파란 머리 캐릭터가 아래에서 놀란 표정으로 붙잡고 있음. 양쪽에 "풍선아트", "달콤 솜사탕" 부스. 뒤쪽에 동물 캐릭터 관중.

### A — 영꾸꾸 둥실 떠오르기

```
카메라 고정. 이미지 배경 그대로 활용. 석양빛 축제장. 초록 비니 캐릭터가 알록달록 풍선 묶음에 매달려 공중으로 둥실 떠오름. 발이 완전히 땅에서 떠있고 다리가 허공에서 까딱거림. 파란 머리 캐릭터가 아래에서 놀란 입을 크게 벌리며 양손을 뻗어 초록 비니 캐릭터의 바지단을 간신히 잡고 있음. 양쪽 "풍선아트"와 "달콤 솜사탕" 부스 조명이 따뜻하게 켜져있음. 뒤쪽 동물 캐릭터들이 놀라서 쳐다봄. 음악 없음, 효과음만 있음.
```

### B — 풍선 터지며 착지

```
카메라 고정. 이미지 배경 그대로 활용. 석양빛 축제장. 초록 비니 캐릭터가 공중에 떠있는 상태에서 풍선 하나가 "펑!" 터짐. 살짝 아래로 내려옴. 이어서 하나 더 터지며 점점 내려옴. 파란 머리 캐릭터가 아래에서 팔을 벌리고 받을 준비. 초록 비니 캐릭터가 천천히 내려와 파란 머리 캐릭터 품에 안착. 둘 다 안도한 표정. 뒤쪽 축제 조명이 석양과 함께 빛남. 음악 없음, 효과음만 있음.
```

### C — 파발이가 끌어내리기 성공

```
카메라 고정. 이미지 배경 그대로 활용. 석양빛 축제장. 파란 머리 캐릭터가 초록 비니 캐릭터의 다리를 꽉 잡고 온 힘을 다해 아래로 끌어당김. 얼굴에 힘을 주며 발을 바닥에 버팀. 초록 비니 캐릭터가 조금씩 내려옴. 풍선 줄 몇 개가 손에서 놓여 하늘로 날아감. 나머지 풍선과 함께 초록 비니 캐릭터가 땅에 착지. 둘 다 주저앉으며 안도의 한숨. 뒤쪽 동물 캐릭터들이 박수치는 동작. 음악 없음, 효과음만 있음.
```

## 🎬 예시 3 — 벤치에서 간식 먹기

> 기획상: 파트12 — 축제 구경 후 벤치에 앉아 간식 먹으며 쉬는 장면

**이미지 분석**: 두 캐릭터가 나무 벤치에 나란히 앉아있음. 파란 머리 캐릭터가 떡꼬치를 들고, 초록 비니 캐릭터가 분홍 솜사탕을 들고 있음. 뒤쪽에 "FESTIVAL" 배너, "WELCOME" 간판, 풍선.

### A — 나란히 앉아 맛있게 먹기

```
카메라 고정. 이미지 배경 그대로 활용. 두 캐릭터가 나무 벤치에 나란히 앉아있음. 파란 머리 캐릭터가 떡꼬치를 양손으로 들고 한 입 크게 베어 물음. 볼이 부풀어 오르며 씹는 동작. 초록 비니 캐릭터가 분홍 솜사탕을 얼굴 가까이 가져가 한 입 뜯어먹으며 눈을 감고 행복한 표정. 뒤쪽 "FESTIVAL" 배너와 "WELCOME" 간판, 풍선이 보임. 바람에 풍선이 살짝 흔들림. 음악 없음, 효과음만 있음.
```

### B — 먹다가 서로 쳐다보며 웃기

```
카메라 고정. 이미지 배경 그대로 활용. 두 캐릭터가 벤치에 앉아 각자 간식을 먹는 중. 파란 머리 캐릭터가 떡꼬치를 먹다가 초록 비니 캐릭터 쪽을 봄. 초록 비니 캐릭터도 솜사탕 먹다가 고개를 돌려 눈이 마주침. 잠시 멈췄다가 둘 다 동시에 웃음. 발을 동시에 앞뒤로 까딱거림. 평화롭고 행복한 순간. 뒤쪽 축제 부스와 분홍 체크 테이블보가 보임. 음악 없음, 효과음만 있음.
```

### C — 먹다가 발 흔들기 + 기지개

```
카메라 고정. 이미지 배경 그대로 활용. 두 캐릭터가 벤치에 앉아 간식을 거의 다 먹은 상태. 파란 머리 캐릭터가 떡꼬치 마지막 하나를 입에 넣고 만족스러운 표정으로 배를 쓰다듬. 초록 비니 캐릭터가 솜사탕 막대만 남은 채 양손을 위로 뻗으며 기지개. 둘 다 발을 앞뒤로 살짝 흔들며 여유로운 표정. 뒤쪽 풍선이 하늘에 떠다니고 "WELCOME" 간판이 바람에 살짝 흔들림. 음악 없음, 효과음만 있음.
```
