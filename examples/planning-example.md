# 💡 기획서 예시 — 파발이 × 영꾸꾸 축제 프로젝트

> STEP 1(기획) 프롬프트를 실행했을 때 나오는 결과물의 실제 예시입니다.

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트 유형 | 캐릭터 단편 애니메이션 |
| 주인공 | 파발이 — 파란 곱슬머리, 베이지 피부, 흰 티셔츠, 검정 반바지, 파란 스니커즈 |
| 서브 캐릭터 | 영꾸꾸 — 초록 니트 비니, 하얀 몸, 분홍 코, 파란 상의, 갈색 멜빵바지 |
| 배경 캐릭터 | 여우, 곰, 토끼, 고슴도치 등 동물 캐릭터들 (축제 관객/상인) |
| 배경 | 여름 축제장 — 야외 광장, 셀러 부스, 푸드트럭, 폭포, 벤치 |
| 아트 스타일 | 3D 펠트/봉제인형 스타일, 부드러운 조명, 파스텔 색감 |
| 제작 방식 | AI 이미지 → 이미지 투 비디오 → Suno 음악 → 편집 |

## 2. 전체 스토리 구조

```
[시작] 파발이 혼자 축제장 도착
  → 설렘과 기대감, 관객에게 세계관 소개
  ↓
[전개] 혼자 구경 (마켓 → 핫도그 → 솜사탕 → 돌아다니기)
  → 호기심과 행복, 캐릭터 매력 어필
  ↓
[전환] 돌아다니다 멈춤 → 영꾸꾸 발견!
  → 깜짝 놀람, 새 캐릭터 등장으로 이야기 전환
  ↓
[발전] 합류 → 하트 포즈 → 함께 달리기
  → 우정 확인, 에너지 상승, 함께하는 즐거움
  ↓
[클라이맥스] 풍선 해프닝 (날아감 → 구출)  ⭐
  → 긴장감 최고조, 우정의 시험, 극적 감동
  ↓
[해소] 먹거리 사서 함께 먹방
  → 클라이맥스 후 안도, 평화로운 일상 복귀
  ↓
[엔딩] 벤치에서 폭포 바라보며 마무리
  → 잔잔한 여운, "오늘 최고였다" 감정
```

## 3. 파트별 상세 기획

| 파트 | 파트명 | 기획 의도 | 감정선 | 전환 로직 |
|------|--------|-----------|--------|-----------|
| 1 | 오프닝 | 축제장 전경, 설렘 | 🟡 설렘 | → 부스 구경 시작 |
| 2 | 셀러 마켓 | 여우 부스에서 물건 구경 | 🟡 호기심 | → 냄새에 이끌림 |
| 3 | 핫도그 가판대 | 먹거리 발견, 놀란 표정 | 🟡→🟢 | → 솜사탕 발견 |
| 4 | 솜사탕 | 혼자 먹으며 행복 | 🟢 행복 | → 돌아다니기 |
| 5 | 돌아다니기 | 이곳저곳 뛰어다님 → 멈춤 | 🟡→🔴 | → 영꾸꾸 발견! |
| 6 | 만남 | "어?! 영꾸꾸?!" | 🔴→🟢 | → 합류 제안 |
| 7 | 합류 | "같이 돌아다닐래?" | 🟢 우정 | → 기념 포즈 |
| 8 | 하트 포즈 | 하트 만들기 | 🟢🟢 | → 함께 달리기 |
| 9 | 함께 달리기 | 축제 속으로 달려감 | 🟢🟢 | → 풍선 발견 |
| 10 | 풍선 해프닝 | 영꾸꾸 날아감 → 구출 | 🔴→💙 ⭐ | → 안도 → 먹거리 |
| 11 | 먹거리 | 핫도그 & 솜사탕 먹방 | 🟢 평화 | → 벤치로 |
| 12 | 벤치 간식 | 떡꼬치 & 솜사탕 먹기 | 🟢→💙 | → 엔딩 |
| 13 | 엔딩 | 폭포 바라보며 마무리 | 💙 여운 | 페이드아웃 |
