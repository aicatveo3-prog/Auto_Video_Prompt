🖼️ 이미지 합치기

여러 이미지를 업로드하면 한 줄에 4개씩 · 총 8장을 한 시트로 묶어 JPG로 저장합니다.
8장이 넘으면 자동으로 여러 장으로 나뉩니다 (9~16번째는 2번째 시트로).
모든 처리는 내 브라우저 안에서만 실행됩니다. 이미지가 서버로 전송되지 않습니다.

1️⃣ 이미지 업로드

📂
클릭해서 이미지 선택 또는 여기로 드래그 & 드롭
JPG · PNG · WEBP · GIF · 여러 장 동시 선택 가능
아직 업로드된 이미지가 없습니다.

💡 썸네일을 드래그하거나 ◀ ▶ 버튼으로 순서를 바꿀 수 있습니다.

📖 사용 방법

  1. 이미지 업로드 — 클릭해서 선택하거나 드래그 & 드롭 (여러 장 한 번에 가능)
  2. 순서 확인 — 썸네일을 드래그하거나 ◀ ▶ 버튼으로 순서 조정
  3. 설정 조정 — 한 줄에 몇 개(기본 4개), 간격, 배경색 등
  4. 🔗 이미지 합치기 클릭
  5. ⬇️ JPG 다운로드 클릭

⚙️ 설정 설명

설정설명
한 줄에 몇 개가로로 배치할 이미지 수 (기본 4개)
한 장당 이미지 수한 시트에 담을 이미지 수 (기본 8개 = 4열 × 2행). 넘으면 자동으로 여러 장으로 분할. 0이면 전체를 한 장에
셀 너비각 이미지 칸의 너비. 0이면 자동 (가장 큰 이미지 기준, 최대 1200px)
셀 비율 = 자동원본 비율을 그대로 유지. 행마다 높이가 자동으로 맞춰짐 (권장)
셀 비율 = 16:9 등모든 칸을 같은 비율로 통일. 크기가 다른 이미지를 격자로 깔끔하게 정렬할 때
꽉 채우기칸을 가득 채우되 가장자리가 일부 잘림
비율 유지이미지 전체가 보이되 여백이 생김
순번 표시우측 하단에 1, 2, 3… 번호를 작게 표시. 여러 장으로 나뉘어도 번호는 이어서 붙습니다 (2번째 시트는 9번부터) — 스토리보드 정리에 유용

💡 활용 팁

  • 스토리보드 만들기 — 생성한 이미지를 순서대로 올리고 순번 표시를 켜면 장면 순서를 한눈에 볼 수 있는 시트가 됩니다
  • AI에게 한 번에 보여주기 — 이미지 13장을 따로 첨부하는 대신 합쳐서 1장으로 올리면 AI가 전체 흐름을 파악하기 쉽습니다
  • 캐릭터 일관성 확인 — 같은 캐릭터가 나온 이미지를 모아 합치면 외형이 어긋난 부분을 바로 찾을 수 있습니다
  • 비교용 시트 — 같은 장면의 A / B / C 버전을 나란히 놓고 고를 때

🔒 개인정보

이 도구는 JavaScript Canvas API로 브라우저 안에서만 동작합니다.
업로드한 이미지는 서버로 전송되지 않으며, 저장되지도 않습니다. 페이지를 닫으면 모두 사라집니다.
