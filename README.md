# 🎬 Auto Video Prompt — AI 영상 제작 파이프라인 가이드

> **어떤 AI 채팅에서든, 이 가이드를 참조하면 동일한 품질의 영상 제작 프로세스를 실행할 수 있습니다.**

---

## 📖 이 프로젝트는 무엇인가요?

AI 도구들(ChatGPT, Claude, Gemini 등)이 **영상 제작 전 과정**을 체계적으로 도와줄 수 있도록 만든 **표준 제작 가이드**입니다.

한 줄의 URL만 AI에게 전달하면, AI가 이 문서를 읽고 **기획 → 이미지 → 영상 → 음악**까지 전체 파이프라인을 일관되게 실행합니다.

---

## 🎯 제작 방식

```
AI 이미지 생성 → 이미지 투 비디오(I2V) → AI 음악 생성 → 편집
```

---

## 🔄 4단계 파이프라인

| STEP | 단계 | 입력 | 출력 | 상세 문서 |
|------|------|------|------|-----------|
| **1** | 🎬 기획 | 영상 주제/컨셉 | 스토리 구조, 캐릭터, 감정선, 이미지 목록 | [pipeline.md](pipeline.md) → [프롬프트](prompts/step1-planning.md) |
| **2** | 🖼️ 이미지 생성 | 기획서 | 장면별 AI 이미지 프롬프트 | [pipeline.md](pipeline.md) → [프롬프트](prompts/step2-image.md) |
| **3** | 🎥 이미지→비디오 | 생성된 이미지 | 이미지당 3개(A/B/C) 비디오 프롬프트 | [pipeline.md](pipeline.md) → [프롬프트](prompts/step3-video.md) |
| **4** | 🎵 음악 생성 | 기획 + 장면 구성 | 씬별 Suno 영어 프롬프트 + 스타일 태그 | [pipeline.md](pipeline.md) → [프롬프트](prompts/step4-music.md) |

## 📏 공통 규칙

이 프로젝트의 모든 프롬프트에 적용되는 규칙:

- ✅ **비디오 프롬프트**: 카메라 고정 / 배경 유지 / 음악 없음, 효과음만
- ✅ **이미지당 프롬프트**: 최소 3개 (A: 기본, B: 감정 강화, C: 변형)
- ✅ **음악 프롬프트**: 영어 / Instrumental / 프롬프트 + 스타일 태그
- ✅ **출력 형식**: 마크다운 표 + 코드블록 + 추천표 + 흐름 연결

> 상세 규칙은 [rules.md](rules.md)를 참고하세요.
